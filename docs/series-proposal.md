# 系列方案 · 第一稿：《ECHOES（エコーズ）》

> 2026-10-15。导演定下的方向：**恋人**、**可以分集发布**、最喜欢的角色是 **David 和 Lucy**。
> 这份方案取代之前的《超频 OVERCLOCK》（外卖骑手）和"脑仓骑手"两版。片名是暂定的。
> **这一稿只定故事和人物的内核。** 造型只写方向，具体样子等内核确认后，再让 Codex 画概念对比图来选。

---

## 0. 这次怎么想的

之前几版都是先定一个职业，再往上套故事和造型，所以人物一直立不起来。这次反过来：

**伤口 → 想要什么 → 愿意付出什么 → 世界怎么逼他 → 他是干什么的 → 长什么样**

从《边缘行者》里学的是结构，不抄内容：

| 原作的结构 | 我们的版本 |
| --- | --- |
| 起点是一次失去（母亲死了，留下债务） | 母亲**还活着，但已经忘了他** |
| 一份既是礼物也是诅咒的遗产（斯安威斯坦） | 母亲留下的偷记忆工具 |
| 遇见一个有具体梦想的人（Lucy 想去月球） | 遇见一个没有过去的女孩，她想**亲眼**看一次海 |
| 一个"家"（Maine 的团队） | 一个偷记忆的小团伙 |
| 镜子角色（Maine 的结局预告了 David 的结局） | **他的母亲**就是镜子：卖光记忆的人会变成什么样 |
| 代价长在身上（义体越来越多） | 女主每潜入一次别人的大脑，**眼睛里就多一道光的裂痕** |
| 讽刺的愿望实现（登上荒坂塔顶） | 她终于亲眼看到了海，**却已经不记得身边的他** |

---

## 1. 一句话

在一个记忆可以买卖的城市，一个偷记忆的少年爱上了一个没有过去的女孩。她想要一段只属于自己的回忆，而他们为了彼此付出的一切，最后都让对方忘了自己。

## 2. 主题

**能被拿走的，到底算不算是你的？**

在这座城市里，钱、身体、记忆都能买卖。两个主角都以为只要拿回、买回、偷回某样东西，就能保住爱的人。最后他们才发现，唯一拿不走的，是**此刻正在发生的事**。

---

## 3. 世界：记忆经济

沿用之前的 **Stack City**：一座往地下挖的垂直城市，越往下越穷、越暗，终年不见天日。

- **记忆可以提取、复制、买卖。** 太阳穴上装一个接口，就能把一段记忆导出来。导出以后，你自己就不再记得了。
- **有钱人买穷人的记忆。** 顶层的人生活安全、干净，也很无聊，他们花大价钱买真实的人生：初恋、打架、海边的日落、被妈妈抱着的感觉。
- **穷人卖记忆。** 交房租、看病、还债。最值钱的是**幸福的记忆**，所以穷人越卖越不快乐。
- **记忆交易所**由大公司 ZENITH 经营，表面上是合法的"体验流通"。
- **记忆小偷**：从有钱人的脑子里把买来的记忆偷出来，转卖到黑市。
- **卖光记忆的人**被叫作"空壳"（ブランク）。他们还活着，会笑，会吃饭，只是什么都不记得了。

赛博朋克感从哪里来：**连人最私密的东西都成了商品**，而且越幸福越值钱。

## 4. 人物

### Miles（マイルズ），男主

| 层次 | 内容 |
| --- | --- |
| **伤口** | 他小时候家里很穷，母亲一段一段地卖掉自己的记忆养活他，最后把关于他的记忆也卖了。现在母亲住在下层的"空壳"收容所里，每次见到他，都礼貌地问"你是谁" |
| **想要什么** | 攒够钱，从交易所把母亲的记忆**买回来**。他打听到，那些记忆被一个顶层富豪买走了，富豪每晚都在重温"被母亲爱着的感觉" |
| **真正需要明白的** | 有些东西是买不回来的。爱一个人，不是把过去拿回来，而是此刻在她身边 |
| **性格** | 冲、倔、不服输，嘴硬心软。为了在乎的人什么都敢干，从来不算代价。**这一点像 David** |
| **缺陷** | 他相信一切都可以拿回来，所以总是透支自己 |
| **身份** | **记忆小偷**。母亲留下了一套老旧的记忆提取工具，那是她当年卖记忆时用的东西。他用这套工具去偷别人的记忆 |
| **代价** | 每做一单，就离"变成母亲那样"更近一步 |

### Iris（アイリス），女主

| 层次 | 内容 |
| --- | --- |
| **伤口** | 她不记得自己是谁。她小时候是交易所的"采集体"，记忆从小就被不停地抽走、卖掉。她从实验设施里逃了出来，脑子里却什么都没有留下 |
| **想要什么** | **一段只属于自己的回忆**。她在偷来的别人的记忆里见过海，但那是别人的。她想**亲眼**看一次真正的海，"这样那段回忆就是我的了" |
| **真正需要明白的** | 她其实已经有了属于自己的回忆，就是和 Miles 在一起的每一天 |
| **性格** | 安静、神秘、有点疏离，偶尔冒出一句很天真的话。对世界充满好奇，因为一切对她都是第一次。**这一点像 Lucy** |
| **特殊能力** | 因为脑子里几乎是空的，别人的大脑不会排斥她，所以她能**潜入别人的记忆里**，比任何机器都快。这是团伙需要她的原因 |
| **代价（看得见）** | 每潜入一次，她自己仅有的记忆就会被冲掉一点，**眼睛里也会多一道发光的裂痕**。片子开头只有一道；到结尾，她的眼睛里满是光的裂纹。她的名字 Iris 本身就是"虹膜"的意思 |

### 他们的关系怎么发展

1. **相遇**：Miles 去偷一个富豪的记忆，在富豪的脑子里撞见了也在偷东西的 Iris。两个小偷在同一段记忆里相遇，那段记忆正好是海边的日落。
2. **靠近**：Iris 没有过去，Miles 是她第一个"自己的回忆"。她开始一样一样地问他：这个叫什么，那个是什么味道。
3. **承诺**：Miles 答应她，等干完最后一票，带她出城去看真正的海。
4. **代价加重**：每干一票，Iris 眼里的裂痕就多一道，她开始忘掉一些小事，比如他们第一次吃的那家店。
5. **互相隐瞒**：Miles 瞒着她去偷那个富豪，想拿回母亲的记忆；Iris 瞒着他，偷偷卖掉自己的记忆，替他还债。
6. **结局**：两个人都为对方付出了自己最珍贵的东西。

### 镜子角色：Miles 的母亲

她就是这个世界的结局预告：一个卖光了一切的人，还会笑，却不记得自己爱过谁。每一集 Miles 都会去收容所看她一次，观众每看一次，都会更怕 Iris 变成她那样。

### 团伙（"家"）

人数控制在 3 个，方便 AI 制作时保持角色一致：

| 角色 | 作用 |
| --- | --- |
| **老板**：中年记忆贩子，团伙的头 | 像父亲一样照顾他们，最后为了保护他们而死 |
| **司机**：话痨、开改装车 | 团伙里的笑声，后半段的牺牲让观众心碎 |
| **反派线**：交易所的"回收人"，一个身上一点人味都没有的追捕者 | 专门抓逃跑的"采集体"，也就是 Iris |

---

## 5. 结局

最后一票，Miles 闯进富豪的脑子，拿回了母亲的记忆。但他也因此身受重伤，大脑被烧坏，需要一大笔钱才能活下来。

Iris 把自己仅剩的、关于 Miles 的所有记忆都卖了，换来了他的手术费。

Miles 醒过来，带母亲的记忆回到收容所。母亲想起了他，抱着他哭。可他回头去找 Iris，她站在那里，礼貌地问："你是谁？"

最后一集，Miles 还是遵守了承诺，带一个不认识他的女孩出了城，第一次看到了真正的海。Iris 赤着脚踩进海水里，回头对这个陌生的少年笑着说：

> 「海って、本当にあったんだ。……これは、わたしの思い出だね。」
> （海原来真的存在啊。……这是属于我的回忆了吧。）

Miles 笑着点头，**没有告诉她，这已经是她第二次看见他笑了。**

**痛点在哪里**：她终于有了只属于自己的回忆，而那段回忆里，他是一个陌生人。

## 6. 分集结构（6 集，每集 4–6 分钟）

| 集 | 标题（暂定） | 内容 | 情绪 |
| --- | --- | --- | --- |
| 1 | 海边的小偷 | Miles 去收容所看母亲，母亲不认识他。他接下一单，潜入富豪脑中的海边日落，撞见了 Iris。追逃，交易所的回收人现身 | 好奇、心动 |
| 2 | 第一次 | Iris 加入团伙。Miles 带她去吃东西、看霓虹、坐悬浮列车，每样都是她的"第一次"。第一次一起作案，Iris 眼里出现第一道裂痕 | 甜 |
| 3 | 采集体 | Iris 的来历揭开。回收人追上门，老板受伤。Miles 发现母亲的记忆在那个富豪手里 | 不安 |
| 4 | 价格 | 团伙越做越大，Iris 开始忘事。老板为了掩护他们而死。Miles 决定去偷富豪 | 痛 |
| 5 | 两个秘密 | Miles 闯进富豪的脑子，司机牺牲；Miles 拿回母亲的记忆，大脑被烧坏。Iris 卖掉关于他的所有记忆，换来他的手术费 | 最痛 |
| 6 | 海 | 母亲想起了他，Iris 却忘了他。他带着这个陌生的女孩去看海 | 痛，但温柔 |

**制作建议**：先做**第 1 集**（4–6 分钟），加一支 1 分钟的预告片，验证画风、角色一致性和观众反应，再决定后面的节奏。

## 7. 造型方向（只定方向，不定样子）

造型从身份和代价里长出来，具体样子等内核确认后，再让 Codex 画概念对比图来选。

| | Miles | Iris |
| --- | --- | --- |
| 标志性颜色 | **红色**：热、冲、会把自己烧掉 | **冷色**：冰蓝或淡紫，安静、像一张白纸 |
| 最显眼的部件 | **右前臂上那套母亲留下的老旧记忆提取工具**：外露的线缆、一根插进别人太阳穴的探针。工具就是他的身份，就像 Rebecca 的机械臂 | **眼睛**：裂痕会随着剧情一集比一集多，是全片最重要的视觉线索 |
| 代价的痕迹 | 太阳穴的接口周围，有反复使用留下的烫伤 | 眼睛里的光裂纹 |
| 和原作的区别 | 不穿黄色夹克，没有斯安威斯坦 | 不是白色短发，不穿潜网服，没有月球 |

## 9. 需要导演确认的事

1. **这个故事内核行不行？** 特别是结局：她卖掉了关于他的记忆，最后在海边把他当成陌生人。
2. **女主的名字 Iris 行不行？**
3. **6 集、每集 4–6 分钟，先做第 1 集加预告片**，这个节奏可以吗？
4. **有没有哪里特别想改？** 比如你希望 Miles 的结局更惨（像 David 那样死掉），还是保持现在这种"活着但失去"的痛？
