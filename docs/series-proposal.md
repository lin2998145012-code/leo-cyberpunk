# 系列方案 · 第二稿：《ECHOES（エコーズ）》

> 2026-10-15。导演定下的方向：**恋人**、**可以分集发布**、最喜欢的角色是 **David 和 Lucy**。
> 第一稿有很多逻辑漏洞（见第 9 节）。这一稿**先定死世界规则，再让每一处情节都对着规则检查**。
> 只定故事和人物的内核。造型只写方向，内核确认后再让 Codex 画概念对比图。片名暂定。

---

## 1. 一句话

在一个记忆可以买卖的城市，一个偷记忆的少年爱上了一个没有过去的女孩。最后他必须选择：把她忘掉的、关于他的记忆还给她，还是让她留住那段她这辈子唯一真正属于自己的回忆。

## 2. 主题

**爱一个人，就是愿意被她忘记。**

- 母亲为了养活儿子，卖掉了关于儿子的记忆。
- Iris 为了救 Miles，卖掉了关于 Miles 的记忆。
- Miles 最后选择不把那段记忆还给她。

三个人都用"被忘记"来爱一个人。

---

## 3. 世界规则（所有情节都必须符合这 7 条）

Stack City：一座往地下挖的垂直城市，越往下越穷、越暗，终年不见天日。城市在一片沉没的海岸废墟下面。地表的海岸是封锁区，官方说那里有毒，其实没有。这是公司编出来的谎话，为的是让下层的人老实待在地下。

| # | 规则 | 剧情里的作用 |
| --- | --- | --- |
| **R1** | **记忆只能转移，不能复制。** 提取以后，原主人就不再记得了。勉强复制出来的只是模糊、没有感情的"残响"（エコー），一文不值 | 这就是记忆值钱的原因，也是片名的来历 |
| **R2** | 记忆储存在实体的**记忆芯片**里交易。用太阳穴的接口可以导出，也可以植入 | 芯片是看得见、摸得着的道具，可以偷、可以藏、可以扔 |
| **R3** | **植入别人的记忆，永远感觉是"别人的"。** 你会记得那件事，但带着原主人的视角和感受，就像看一部很真实的电影。**只有原主人自己植回去，才会感觉是自己的** | 有钱人买的正是"体验别人的人生"；这也是 Iris 想亲眼看海的原因；母亲拿回自己的记忆后，那些记忆会重新属于她 |
| **R4** | 偷记忆必须趁对方昏迷或熟睡的时候，从接口直接提取。普通小偷只能盲找，要花很长时间。**"潜入者"能进入别人的记忆里定位目标**，几分钟就能找到；潜入时还能带一个人一起进去 | Iris 的价值就在这里；也让两人可以一起"走进"同一段记忆 |
| **R5** | **潜入有代价。** 别人的记忆会冲刷潜入者的大脑，挤掉她自己的一部分记忆，还会损伤大脑。**受损的地方空出来也不能再用**，就像烧坏的硬盘扇区。所以潜入得越多，能装下的新记忆就越少，装满以后，新的会把旧的挤掉 | Iris 的代价，看得见的就是她眼里的裂痕；也是结局里那个两难选择的来由 |
| **R6** | 卖光记忆的人叫"空壳"（ブランク）。他们还活着、会笑、会吃饭，只是不记得自己是谁、爱过谁 | Miles 的母亲，就是 Iris 的未来 |
| **R7** | **越幸福的记忆越值钱。** 交易所合法收购普通人卖的记忆；偷来的记忆只能卖到黑市 | 穷人越卖越不快乐；Iris 是逃犯，只能走黑市 |

## 4. 人物

### Miles（マイルズ），男主

| 层次 | 内容 |
| --- | --- |
| **伤口** | 小时候家里很穷，母亲一段一段地把记忆卖给交易所养活他。最后卖出去的，是最值钱的那一段：**她做母亲的全部记忆**，也就是关于他的一切。现在她是收容所里的一个空壳，每次见到他都礼貌地问"你是谁" |
| **他为什么当小偷** | 这段记忆被一个顶层的收藏家买走并植入了。按 R1，交易所里已经没有这段记忆了；按 R2，它现在在收藏家的脑子里。**买不回来，只能偷回来。**他用母亲当年在街头卖记忆时用的那台廉价提取器，自学成了记忆小偷 |
| **想要什么** | 从收藏家的脑子里把母亲的记忆偷回来，植回她的脑子里。按 R3，那些记忆会重新属于她 |
| **真正需要明白的** | 把记忆还回去，不一定就是爱。爱是尊重对方自己的选择 |
| **性格** | 冲、倔、嘴硬心软，为了在乎的人从不算代价。**这一点像 David** |
| **看得见的代价** | 那台提取器又老又粗糙，每用一次都会反冲，太阳穴的接口周围全是烫伤 |

### Iris（アイリス），女主

| 层次 | 内容 |
| --- | --- |
| **伤口** | 她是交易所"采集计划"的孩子，从小记忆就被不停地抽走、卖掉。16 岁那年她从设施里逃了出来，脑子里几乎什么都没剩下 |
| **能力** | **潜入者**（R4）。她的脑子几乎是空的，别人的大脑不会排斥她，所以她是城里最快的潜入者。交易所一直在追捕她：她是他们最值钱的"财产" |
| **想要什么** | **一段只属于自己的回忆。**她潜入过别人记忆里的海，但按 R3，那永远是别人的海。她想**亲眼**看一次真正的海 |
| **为什么不植入一段海的记忆** | 按 R3，植入的记忆永远是别人的。她从小就被人往脑子里塞别人的东西、往外抽自己的东西，她比谁都清楚那种感觉 |
| **真正需要明白的** | 她其实已经有了属于自己的回忆：和 Miles 在一起的每一天 |
| **性格** | 安静、神秘、有点疏离，偶尔冒出一句很天真的话。一切对她都是第一次。**这一点像 Lucy** |
| **看得见的代价** | 每潜入一次（R5），眼睛里就多一道发光的裂痕。Iris 这个名字本身就是"虹膜"的意思 |

### 镜子角色：Miles 的母亲

卖光一切的人，还会笑，却不记得自己爱过谁（R6）。每一集 Miles 都会去收容所看她一次，观众每看一次，都会更怕 Iris 变成她那样。

### 团伙（"家"）

| 角色 | 作用 |
| --- | --- |
| **老板**：中年黑市记忆贩子 | Miles 的师父。是他发现了 Iris，把她拉进团伙。最后为了掩护两人而死 |
| **司机**：话痨，开改装车 | 团伙里的笑声。在最后一票中牺牲 |
| **回收人**：交易所派来追捕 Iris 的人，自己就是一个被植满别人记忆的人，没有自己的性格 | 反派。也是 Iris 被抓回去以后会变成的样子 |

## 5. 主线

1. Miles 一个人偷不到收藏家：收藏家买了几千段记忆，盲找根本找不到母亲那一段。**他需要一个潜入者。**
2. 他在一次作案时撞见了 Iris：她已经潜进了目标的脑子里，几秒钟就找到了他找了一个小时都没找到的东西。两人被警报打断，一起逃跑。
3. 老板把 Iris 拉进团伙。Iris 带 Miles 一起潜入一段偷来的海边日落（R4），这是 Miles 第一次见到海，也是两人第一次靠近。
4. 每干一票，Iris 眼里的裂痕就多一道，她开始忘掉一些小事。
5. 她明知道代价，还是答应帮 Miles 偷收藏家。就像 David 为了 Lucy 一次次装义体，**Iris 为了 Miles 一次次潜入。**
6. 最后一票：回收人追了进来。Iris 潜入回收人的脑子，把他被塞满的那些别人的记忆全部冲掉，他变成了一个空壳（R6）。Iris 在收藏家的脑子里找到了母亲的记忆，Miles 把它提取了出来；司机为了掩护他们牺牲。Miles 被提取器的反冲烧伤大脑，必须马上做手术，否则就会死。
7. 他们付不起手术费。按 R7，Iris 身上最值钱的东西，是她最幸福的记忆，而她最幸福的记忆全都和 Miles 有关。**她把关于 Miles 的所有记忆卖到了黑市**，换来了他的手术费。
8. Miles 醒来，把母亲的记忆植回她脑中（R3）。母亲想起了他，抱着他哭。他回头去找 Iris，她礼貌地问："你是谁？"
9. Miles 是小偷。他查到 Iris 的记忆还在黑市贩子的仓库里，没来得及转卖，还装在一枚芯片里。他把**这枚芯片**偷了回来。

## 6. 结局：他的选择

Iris 忘了 Miles，却没有忘记自己的梦：她在认识他之前就想看海了。Miles 对这个陌生的女孩说："我知道一条通往海边的路。" 她犹豫了一下，跟着他走了。不知道为什么，她觉得可以相信这个人。

他们穿过整座城市，爬上了地表。

Iris 赤着脚踩进海水里，回头对这个陌生的少年笑：

> 「海って、本当にあったんだ。……これ、わたしの思い出だね。」
> （海原来真的存在啊。……这是属于我的回忆了吧。）

Miles 手里攥着那枚芯片。黑市医生告诉过他：Iris 的大脑已经被潜入冲刷得太厉害（R5），只能再装下很少的东西。**如果把关于他的记忆植回去，新的记忆就会被挤掉，第一个被挤掉的，就是此刻的这片海。**

他可以让她重新记起爱过他，代价是拿走她这辈子唯一真正属于自己的回忆；也可以什么都不做，从此在她眼里只是一个陌生人。

他把芯片放回口袋，对她伸出手：

> 「Miles だ。……はじめまして。」
> （我叫 Miles。……初次见面。）

**这一刻他学会了母亲和 Iris 早就懂的事：爱一个人，就是愿意被她忘记。**

## 7. 分集结构（6 集，每集 4–6 分钟）

| 集 | 标题（暂定） | 内容 | 情绪 |
| --- | --- | --- | --- |
| 1 | 小偷 | Miles 去收容所看母亲，母亲不认识他。他潜进一个富人家作案，撞见了已经在潜入的 Iris。警报响起，回收人出现，两人一起逃跑 | 好奇、心动 |
| 2 | 别人的海 | 老板把 Iris 拉进团伙。Iris 带 Miles 潜入一段偷来的海边日落，Miles 第一次见到海。Iris 说："这是别人的海。我想看我自己的。" 第一次一起作案，Iris 眼里出现第一道裂痕 | 甜 |
| 3 | 采集体 | Iris 的来历揭开。回收人追上门。Miles 向 Iris 坦白母亲的事，以及收藏家 | 不安 |
| 4 | 价格 | Iris 开始忘事。她答应帮 Miles 偷收藏家。老板为了掩护他们而死 | 痛 |
| 5 | 最后一票 | 偷收藏家。回收人追来，被 Iris 冲成了空壳；司机牺牲。Miles 拿到母亲的记忆，大脑被烧伤。Iris 卖掉关于他的记忆，换来手术费 | 最痛 |
| 6 | 初次见面 | 母亲想起了他，Iris 忘了他。他从黑市贩子手里偷回装着她记忆的芯片，然后带这个陌生的女孩去看海，做出选择 | 痛，但温柔 |

**制作建议**：先做第 1 集，再配一支 1 分钟的预告片，验证画风、角色一致性和观众反应。

## 8. 造型方向（只定方向）

| | Miles | Iris |
| --- | --- | --- |
| 标志性颜色 | **红色**：热、冲、会把自己烧掉 | **冷色**：冰蓝或淡紫，安静，像一张白纸 |
| 最显眼的部件 | **右前臂上那台母亲留下的老旧提取器**：外露的线缆，一根插进别人接口的探针。工具就是他的身份 | **眼睛**：裂痕一集比一集多，是全片最重要的视觉线索 |
| 代价的痕迹 | 太阳穴接口周围的烫伤 | 眼睛里的光裂纹 |
| 和原作的区别 | 不穿黄色夹克，没有斯安威斯坦 | 不是白色短发，不穿潜网服，没有月球 |
| 关键道具 | **记忆芯片**：发光的小芯片，母亲的记忆、Iris 的记忆都装在里面 | — |
