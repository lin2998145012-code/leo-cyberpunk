# 原片参考分析：《赛博朋克：边缘行者》官方预告

这份分析基于两段官方宣传素材，不是凭印象写的：

| 素材 | 来源 | 规格 |
| --- | --- | --- |
| 正式预告 | Netflix 官方预告（B 站 IGN 中国转载，BV1Je4y1D7ts） | 166 秒，1080p，23.976fps，206 个镜头 |
| 先导 PV | 官方先导 PV（B 站转载，BV1h3411G7Zc p2） | 77 秒，77 个镜头 |

分析方法：用 `tools/analyze_video.py` 做镜头切分、色彩统计和换画间隔统计；206 个镜头逐一看缩略图；挑 4 个人物镜头逐帧检查。

**适用范围**：预告片的剪辑比正片快得多，也会集中放最激烈的镜头。下面的**镜头时长**只代表预告片的节奏，不代表正片；**色彩、作画、特效**的结论可以直接用于正片风格。原片截图和视频只用于分析，没有放进仓库。

## 1. 色彩：青蓝和红为主，品红很少

饱和像素的色相分布（两段素材分别统计）：

| 色相 | 正式预告 | 先导 PV |
| --- | --- | --- |
| 红 | 17% | 37% |
| 青 + 天蓝 + 蓝 | 50% | 35% |
| 黄 + 橙 | 11% | 18% |
| 绿 | 6% | 5% |
| 紫 + 品红 + 玫红 | 13% | 6% |

**纠正**：之前的方案把品红 `#FF2A6D` 写成主色，这是凭印象写的，是错的。实测品红只占 0.5%–4%。真正的主色是**青蓝**和**红**，黄色和绿色作点缀。

实测色板（正式预告，k-means 聚类）：

- **暗部和底色**：`#140E1E` 紫黑、`#17184D` 深靛蓝、`#194140` 深青、`#481920` 暗红、`#424076` 灰紫
- **亮部**：`#EDF5ED` 偏青的白（高光和曝白背景几乎都偏青绿，不是纯白）
- **高饱和点缀色**：青 `#29DBD5`、红 `#E83F34`、深红 `#B02324`、电黄 `#F4FC32`、蓝 `#249DBA`、靛紫 `#5453BB`、绿 `#46D669`、金 `#E6B421`

另外三个数据：

- **阴影都带色**：暗部像素里 98%（PV 里 94%）带明显的色彩饱和度，阴影是深蓝、深紫、深红，**几乎没有灰黑色阴影**。这是最容易被 AI 做错的一点。
- **整体饱和度很高**：非黑像素的平均饱和度是 159/255，58% 的像素属于高饱和。
- **纯黑占 24%**：大面积纯黑用于闪切黑帧、剪影和夜景。

## 2. 光影和人物上色

逐帧看了 David、Lucy、Gloria、Dorio 的镜头：

- **线稿细，粗细均匀**：线是细的深色线，粗细变化不大。之前方案里写的"粗轮廓线、粗细变化明显"不对，已改正。
- **一层硬阴影**：人物通常只有一层阴影，边缘是硬的，没有渐变。
- **阴影面积很大**：很多特写里大半张脸都在阴影里（深紫或深蓝），只靠背景亮光或边缘光勾出轮廓。
- **彩色边缘光**：青色或红色的边缘光画成硬边色块，贴在轮廓一侧（例如 Lucy 特写左侧的青色光条）。
- **同一张画换配色**：同一个镜头会快速切换几套配色，比如 David 的特写在青色和正常肤色之间来回切。
- **人物平涂、背景有质感**：人物是平涂，背景要么是虚化的景深（白天开车的镜头），要么是很细的手绘纹理（龟裂的地面、城市夜景）。

## 3. 作画帧率：人物一拍二、一拍三，镜头和特效一拍一

整片统计"每帧都在变"的比例很高（69%–82%），但逐帧看后，原因是镜头运动、背景虚化、光效、颗粒每帧都在变。人物本身是这样画的：

| 镜头 | 内容 | 实测 |
| --- | --- | --- |
| Lucy 特写说话 | 对白 | 每 3 帧换一张画（一拍三），背景完全不动 |
| Gloria 开车说话 | 对白 + 移动背景 | 嘴型一拍二；车窗外背景每帧都在动 |
| David 转头 | 表情动作 | 每 2–3 帧换画，一拍二和一拍三混用 |
| Dorio 跳下落地 | 动作 | 动作中一拍二，落地后停 3 帧亮相 |

**结论**：人物用一拍二或一拍三；镜头运动、背景、特效、字幕动画用一拍一。对白镜头偏一拍三，动作镜头偏一拍二，落地或亮相时停几帧。

这对 AI 视频的意思是：AI 生成的镜头是人物和背景混在一起的单层画面，整段降帧会让镜头运动也一起卡顿。所以：

- **固定机位的镜头**：整段降到一拍二或一拍三
- **有运镜的镜头**：人物和背景分层生成，只给人物层降帧；做不到分层的就不降帧，只靠冲击帧和配色营造手绘感

## 4. 剪辑节奏（仅代表预告片）

| 镜头时长 | 正式预告（206 个） | 先导 PV（77 个） |
| --- | --- | --- |
| ≤ 0.25 秒（6 帧以内） | 77 | 25 |
| 0.25–0.5 秒 | 59 | 17 |
| 0.5–1 秒 | 50 | 13 |
| 1 秒以上 | 20 | 22 |
| 中位数 | 0.31 秒 | 0.38 秒 |

6 帧以内的极短镜头大部分不是普通镜头，而是下面这些手法：

- **黑帧闪切**：两个镜头之间插 2–4 帧纯黑
- **频闪**：同一个镜头和黑帧交替，或者同一张画在两套配色之间来回切
- **冲击帧**：2–5 帧的黑白高反差剪影或纯色画面
- **故障转场**：2–7 帧的数字故障、横向像素条纹

## 5. 特效清单（按出现频率）

1. **整屏单色**：整个画面染成单一色调（红、绿、青），只保留明暗。大量用在暴力、失控和赛博精神病的场面。在正式预告里，一整段打斗都是全红画面。
2. **横向光条和故障**：紫白色的横向光条、扫描线和像素错位，用作转场和情绪爆点。
3. **X 光义体透视**：人体骨骼和义体的透视画面，红、青、绿三色版本快速切换，带色差（RGB 分离）。
4. **冲击帧**：黑白反转剪影；或者人物背后爆开一圈白光，配放射状裂纹。
5. **速度感**：动态模糊加速度线；横向拉伸的光效和残影。
6. **镜头光晕**：横向的变形镜头光晕（anamorphic flare）和强辉光，常用在逆光和人物登场。
7. **HUD 界面**：红色系的扫描框、数据下载进度、警告图标，叠在画面上。
8. **分屏变色**：画面一半是青色故障效果，一半是正常配色。

## 6. 排版（预告片的平面设计）

- 标语：大号**粗斜体黄色日文**压在**巨大的深青色英文窄体字**上（例如 `TAKE TO THE EDGE` / `エッジを踏み越えるんだ`）
- 角色名卡：黄绿渐变的粗窄体英文名，上方加小号片假名
- 这是预告片的包装设计，正片里不一定这样用，可以用于自己的预告和标题卡
