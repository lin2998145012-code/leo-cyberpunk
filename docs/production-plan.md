# AI 生成赛博朋克风格动画：实现方案

目标：用 AI 图像 / 视频生成工具，做出接近《赛博朋克：边缘行者》（Studio Trigger）质感的原创动画短片。

> 先说结论：现阶段 AI 还不能“一句话出成片”。能做出好效果的流程是 **“AI 负责画和动，人负责导演、选片、修图和后期”**。
> 决定成片质量的主要是三件事：**角色和画风一致**、**镜头语言**、**后期合成**。只靠写提示词是到不了这个水平的。

---

## 0. 先定范围：从 1–2 分钟的样片开始

| 项目 | 建议 |
| --- | --- |
| 第一个目标 | 60–120 秒的预告片 / 样片（约 30–50 个镜头） |
| 单镜头时长 | 2–4 秒（边缘行者节奏快，镜头短，正好避开 AI 视频时间越长越崩的问题） |
| 角色数量 | 1–2 个主角 + 少量路人，角色越少越容易保持一致 |
| 对白 | 少，用画外音、旁白、音乐撑节奏，能大大降低口型同步的难度 |
| 周期 | 1 人业余：4–8 周；2–3 人小组：2–4 周 |

**版权提醒**：可以借鉴“画风”，但不要直接用 David、Lucy 这些角色，也不要用 CDPR、Trigger 的 logo 和设定名称，否则不能商用或公开投稿。主角、城市、公司名都自己原创。

## 1. 拆解“边缘行者风格”：要让 AI 复现什么

把风格拆成能写进提示词和后期的具体元素。以下要点来自对官方预告的实测分析，数据和方法见 [原片参考分析](reference-analysis.md)。

**画面**
- 赛璐璐平涂，人物通常只有一层硬阴影，没有渐变
- 线稿细，粗细均匀，靠色块而不是粗线条撑画面
- 阴影面积大，**阴影一定带色**（深靛蓝、深紫、深红），实测暗部 94%–98% 的像素都带饱和色，几乎没有灰黑色阴影
- 主色是**青蓝**和**红**：青 `#29DBD5`、红 `#E83F34`、深红 `#B02324`；点缀色是电黄 `#F4FC32`、绿 `#46D669`；底色是紫黑 `#140E1E`、深靛蓝 `#17184D`、深青 `#194140`。品红实测只占 0.5%–4%，不是主色
- 硬边的彩色边缘光（青或红）贴在轮廓一侧
- 人物平涂，背景虚化（景深）或者是很细的手绘纹理
- 大透视、鱼眼、极端仰俯角

**动态（Trigger 的特点）**
- 人物一拍二或一拍三（对白偏一拍三，动作偏一拍二，落地亮相停几帧），镜头运动、背景和特效一拍一
- 冲击帧：黑白反转剪影，或者人物背后爆开一圈白光
- 黑帧闪切、频闪（同一张画在两套配色之间来回切）
- 速度线、动态模糊、残像

**后期质感**
- **整屏单色**：整个画面染成一种颜色（红、绿、青），用于暴力和失控场面，是最有辨识度的手法之一
- 横向光条和故障转场、色差（RGB 分离）、变形镜头光晕、辉光
- X 光义体透视、红色 HUD 界面叠加
- 大号粗斜体黄色日文标语叠在深青色英文大字上（预告片的包装设计）

> 关键认识：AI 视频天生输出“丝滑 24/30fps”的运动，看起来“飘”，**和 Trigger 风格是反着的**。所以要在后期给人物降到一拍二或一拍三，再手工插入冲击帧，这一步是“像不像”的分水岭（见第 6 节）。

## 2. 整体流程

```
剧本 → 分镜 / 镜头表 → 画风圣经 + 角色设定
     → 每个镜头生成【关键帧图】（首帧 / 尾帧）→ 修图
     → 图生视频（每镜头抽 4–8 次，挑最好的）
     → 降帧 + 冲击帧 + 特效合成 → 调色
     → 配音 / 口型 / 音乐 / 音效 → 剪辑 → 超分输出
```

核心原则：**永远用“图生视频”，不要“文生视频”**。先把每个镜头的画面用图像模型做到满意，再让视频模型去“动起来”，一致性和可控性会好很多。

## 3. 工具选型

> **本项目全程使用 Higgsfield。** 每一步对应 Higgsfield 的哪个功能、人物一致性怎么保证，见 [Higgsfield 制作流程](higgsfield-workflow.md)。下面是通用的选型思路，留作参考。
>
> 提示词里不要写作品名、工作室名或艺术家名字，Higgsfield 的版权过滤会拦截。

### 3.1 图像（画风、角色、关键帧）

| 用途 | 推荐 | 说明 |
| --- | --- | --- |
| 风格探索 / 概念图 | Midjourney（`--sref` 风格参考、`--oref` 角色参考） | 出图审美最好，适合做风格圣经 |
| 角色一致的关键帧 | Nano Banana（Gemini 图像）、Flux Kontext、Seedream（即梦） | 给参考图就能保持同一角色换姿势、换场景 |
| 最高可控（本地） | ComfyUI + Flux / Illustrious / Qwen-Image + **自训 LoRA** + ControlNet | 角色和画风 LoRA 是长期项目的护城河；ControlNet（OpenPose / 线稿 / 深度）控构图 |
| 修图 | Photoshop（创成式填充）/ Krita + AI 插件 | 修手、修脸、修文字、统一线稿 |

### 3.2 视频（让画面动起来）

| 工具 | 强项 | 适合的镜头 |
| --- | --- | --- |
| 可灵 Kling | 首尾帧控制、动作幅度大、动漫表现好 | 打斗、奔跑、大动作 |
| 即梦 / Seedance | 运镜和多镜头叙事、动漫风格稳定 | 运镜、情绪镜头 |
| Google Veo | 画质和物理真实感、原生音频 | 环境、城市空镜、带声音的镜头 |
| 海螺 Hailuo（MiniMax） | 动作表现、性价比 | 动作、表情 |
| Vidu | 动漫风格、多参考图一致性 | 角色互动 |
| Wan（阿里开源，本地 ComfyUI） | 可加载自训 LoRA、无审核限制、批量跑成本低 | 需要严格画风统一的大量镜头 |

建议：**主力 1 个商业平台（如可灵或即梦）+ 1 个备用**，同一个镜头在两家各抽几次，哪个好用哪个。

### 3.3 声音

| 用途 | 推荐 |
| --- | --- |
| 配音 | 真人配音最好；AI 可用 ElevenLabs、CosyVoice / FishAudio（中文好） |
| 口型同步 | 可灵对口型、LatentSync（开源）、Hedra；或者用 Veo 直接生成带对白的镜头 |
| 配乐 | Suno / Udio（边缘行者感：合成器波、工业电子、Darksynth） |
| 音效 | ElevenLabs Sound Effects、MMAudio（开源，按画面生成音效） |

### 3.4 后期

| 用途 | 推荐 |
| --- | --- |
| 剪辑 + 调色 | DaVinci Resolve（免费版够用） |
| 特效合成 | After Effects（Deep Glow、Red Giant Universe 故障插件）或 Resolve Fusion |
| 超分 / 修复 | Topaz Video AI |
| 补帧 / 降帧 | 降帧用 Resolve / ffmpeg；需要补帧时用 RIFE |

### 3.5 硬件

- 只用云端平台：普通电脑即可，成本主要是会员 / 积分
- 本地跑 Wan + LoRA：建议 24GB 以上显存（RTX 4090 / 5090），或者租云 GPU（AutoDL、RunPod）

## 4. 前期制作

### 4.1 剧本和分镜
1. 写一页纸故事（开头、冲突、高潮、结尾）。边缘行者的情绪内核：底层挣扎、义体代价、悲剧浪漫。
2. 拆成镜头表（模板见 `templates/shot-list.csv`），每个镜头写清：景别、机位、运镜、动作、情绪、时长、对白。
3. 画粗分镜，火柴人也可以，也可以用 AI 出草图。**分镜决定成片 70% 的质量**。
4. 用分镜图 + 临时音乐剪一版动态分镜（animatic），先把节奏调对，再开始生成。

### 4.2 画风圣经（Style Bible）
- 用 Midjourney 等工具出 30–50 张风格探索图，挑 5–10 张最满意的作为**风格参考图**，之后每次生成都带上
- 固定色板、线稿粗细、阴影层数、光源规则（例：阴影用深靛蓝或深紫，边缘光用青色或红色），色值参考[原片参考分析](reference-analysis.md)
- 写一段**固定的风格提示词**，所有镜头复用：（最新版本见 [Codex 执行文档](codex-execution.md) 的 `{STYLE}`，下面是早期版本）

```
2D anime TV series style, flat cel shading, single hard shadow layer,
thin clean lineart, large shadow areas tinted deep indigo and violet (no grey shadows),
hard-edged cyan rim light, saturated teal and red neon palette with electric yellow accents,
cyberpunk city at night, dynamic perspective, 2D animation
```

### 4.3 角色设定
- 每个角色出：**三视图**（正 / 侧 / 背）+ **表情表**（6–8 种）+ 关键道具 / 义体特写
- 选一张作为“角色锚定图”，后面所有关键帧都把它作为参考图输入
- 长期项目建议：每个角色用 20–40 张一致的图训练一个 **角色 LoRA**（Flux / Illustrious，可用 kohya_ss、ai-toolkit），再训一个**画风 LoRA**

## 5. 生产阶段：逐镜头生成

### 5.1 关键帧图
每个镜头生成**首帧**，需要精确动作的再生成**尾帧**：
1. 用 ControlNet（姿势 / 线稿）或参考图模型，把角色放进分镜构图
2. 每个镜头出 4–10 张，挑最好的
3. 进 Photoshop 修：手指、义体细节、脸型统一、广告牌文字
4. 定稿后统一调色，保证镜头之间色调连贯

### 5.2 图生视频
提示词结构：**主体动作 + 运镜 + 节奏 / 风格**，动作一次只写一个。

```
[首帧图] + 提示词：
The cyberpunk girl turns her head sharply toward camera, hair whipping,
neon reflections flicker on her face. Slow push-in camera.
2D anime, cel shaded, limited animation, no morphing, consistent character.
```

技巧：
- **短**：生成 5 秒，只用其中最好的 1.5–3 秒
- **首尾帧**：大动作（出拳、拔刀、跳跃）用首尾帧锁住起止姿势，避免中间乱变形
- **抽卡比**：按每个可用镜头 5–10 次生成来留预算
- **难镜头拆开做**：人物和背景分开生成，再在 AE 里合成（例如人物在绿幕 / 纯色背景上动，背景单独做视差运镜）
- **打斗**：拆成“预备 → 冲击帧 → 结果”3 个短镜头快切，比生成一个长打斗镜头好得多（这也正是 Trigger 的剪法）
- 实在生成不出来的镜头，用**静帧 + 后期运镜 + 特效**代替（边缘行者里本来就有大量这类镜头）

### 5.3 文件管理
```
shots/
  S01_C003/
    keyframe_v1.png  keyframe_final.png
    gen_kling_01.mp4 ... gen_kling_08.mp4
    selected.mp4
    prompt.txt        # 记录用的提示词、种子、参数
```
每个镜头都记下提示词和参数，方便复用和返工。

## 6. 后期：从“AI 视频”到“Trigger 动画”的关键一步

### 6.1 降帧成“一拍二 / 一拍三”
AI 生成的视频运动太平滑，要先降帧做出手绘感：
```bash
# 24fps 素材 → 每帧保持两拍（12fps 的动作，24fps 的时间线）
ffmpeg -i selected.mp4 -vf "fps=12,fps=24" -c:v libx264 -crf 14 on_twos.mp4

# 动作戏用一拍三（8fps）
ffmpeg -i selected.mp4 -vf "fps=8,fps=24" -c:v libx264 -crf 14 on_threes.mp4
```
- 实测原片：**对白镜头一拍三，动作镜头一拍二**，落地或亮相时停 3 帧以上；镜头运动、背景、特效一拍一
- AI 生成的画面人物和背景是一层：固定机位的镜头整段降帧；有运镜的镜头要么人物和背景分层生成、只给人物层降帧，要么不降帧
- 进阶：在 Resolve 里用“帧保持”手动挑关键姿势，比均匀抽帧更有 pose-to-pose 的张力
- 降帧后用 `tools/analyze_video.py` 检查换画间隔，和原片数据对比

### 6.2 冲击帧和拖影
- 出拳、命中、枪口火光瞬间：插入 2–5 帧**冲击帧**（黑白高反差剪影，或者人物背后爆开一圈白光加放射状裂纹）
- 镜头之间插 2–4 帧纯黑做闪切；同一张画在两套配色之间来回切做频闪
- 快速动作中插 1–2 帧拉伸 / 残影（用 AI 单独生成一张“smear frame”，或 AE 里做方向模糊）
- 加速度线、镜头震动（AE：Camera Shake / Twitch）

### 6.3 赛博朋克特效合成
- **整屏单色**：暴力、失控场面把整个画面染成一种颜色（红最常见，也有绿、青），只留明暗关系。在 Resolve 里用色调映射或渐变映射就能做，是原片辨识度最高的手法之一
- 辉光和变形镜头光晕：霓虹、眼睛、义体发光（Deep Glow），逆光和人物登场时加横向光晕
- 横向光条、色差、故障：转场、大脑超载、黑客入侵（Red Giant Universe Glitch 或 Resolve 自带）
- X 光义体透视：骨骼和义体的透视画面，红、青、绿三色版本快速切换
- HUD / UI：红色系的扫描框、数据下载进度、警告图标（AE 自己做，或者用素材包）
- 雨、雾、光斑：叠加素材层

### 6.4 调色和统一画面
- 所有镜头套同一个 LUT，再逐镜头微调
- 色彩情绪分段：夜景和日常偏青蓝，战斗偏红，高潮 / 失控用整屏单色；白天的场景饱和度低、偏青白
- 阴影压成深靛蓝或深紫，不要留灰黑色阴影（原片暗部 94%–98% 的像素都带色）
- 最后整体加一层轻微胶片颗粒，能掩盖不同 AI 工具之间的画质差异

### 6.5 超分输出
Topaz 超分到 1080p / 4K（动漫选 Artemis 或 Iris 类模型），注意先超分再降帧，或者降帧后超分时关闭插帧。

## 7. 声音
1. 先定配乐，**按音乐卡点剪辑**（边缘行者 OP 风格的快剪节奏，靠音乐撑起来）
2. 配音：对白尽量放在背影、远景、侧脸、头盔面罩的镜头，减少口型同步需求；正脸说话的镜头用对口型工具处理
3. 音效分层：环境（雨、城市底噪、广告声）+ 动作（枪、刀、义体机械声）+ 界面（HUD 提示音）
4. 混音：对白 -12 ~ -6 dB，音乐让位于对白，冲击帧那一下可以把所有声音抽空 0.2 秒再炸开

## 10. 常见问题和解法

| 问题 | 解法 |
| --- | --- |
| 角色脸 / 服装每个镜头都不一样 | 角色锚定图作为参考 + 角色 LoRA；后期用图像工具修首帧；远景镜头多用剪影 |
| 画面“AI 味”太重、太丝滑 | 降帧到一拍二 / 一拍三，加冲击帧，统一调色加颗粒 |
| 动作变形、肢体乱飞 | 缩短时长，用首尾帧，大动作拆成多个短镜头快切 |
| 动漫画风被视频模型“写实化” | 提示词强调 2D anime、cel shaded；换动漫表现更好的模型；本地用 Wan + 画风 LoRA |
| 文字 / 广告牌乱码 | 关键帧阶段在 PS 里手工放文字，或者后期在 AE 里贴上去 |
| 不同工具生成的镜头质感不统一 | 统一 LUT + 颗粒 + 同样的特效层，在后期“缝”到一起 |
