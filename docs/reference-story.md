# 原作剧情拆解：《赛博朋克：边缘行者》

> 目的：在写我们自己的故事之前，先把原作的完整剧情和结构弄清楚，找出它为什么打动人。
>
> 来源：Cyberpunk Wiki 上 10 集的分集剧情和人物条目（2026-10-15 读取），这里用自己的话整理。**我没有看过正片**（网上没有能合法观看的版本），所以台词、表演和镜头细节都不在这里，只有剧情和结构。凡是 wiki 没写、属于观众推测的内容，都会标出来。

## 1. 分集剧情

| 集 | 标题 | 发生了什么 |
| --- | --- | --- |
| 1 | Let You Down | David 是 Arasaka 学院里的穷学生，母亲 Gloria 是急救员，拼命加班供他上学。他用 Doc 的盗版插件做课程升级，弄坏了学校系统，母子俩被叫到校长室，被暗示"付不起就转学吧"。回家路上，帮派火拼让车出了事故。**创伤小组赶到，但他们不是客户，被跳过了。** David 把母亲送进一家廉价医院做了手术，第二天母亲还是死了，医生说原因是"身体长期过劳"。他回家发现欠房租，门被锁了，只能翻窗进去。医院给的遗物袋里有一个军用 Sandevistan（Gloria 从赛博精神病人的尸体上拿的，本来要卖掉）。Doc 出价 1 万，一天后改口只给 6 千。他领回骨灰，穿着母亲的急救员外套走在街上，收到校长发来的付款明细。同学 Katsuo 打电话嘲笑他母亲的死。他决定把 Sandevistan 装进自己身体。 |
| 2 | Like A Boy | 他装上 Sandevistan，在学校当众打碎 Katsuo 的鼻子，被开除。Arasaka 的 Tanaka（Katsuo 的父亲）看到录像，发现他装了这个都没疯，想把他抓来当实验品。David 在列车上遇到扒手 Lucy，两人一起扒窃。David 用插件过度，昏倒了。**来的救护车发现他没保险，就想把他身上的插件挖下来卖。** Lucy 带他逃走。Doc 说他的身体撑不了几天。Lucy 带他回家，把他母亲的外套改成显示"Edgerunners"。墙上贴着月球移民广告，David 随口嘲笑了一句，Lucy 被刺痛了；她说自己的梦想是去月球，两人一起进了月球模拟。这时 Maine 带人闯进来：Sandevistan 是他的货。（第 3 集揭示：Lucy 认出插件后主动通知了 Maine。） |
| 3 | Smooth Criminal | Maine 得知 Gloria 是他的联络人，而且已经死了，有些动容，但"债还是债"。David 提出留下插件、用干活还债。Lucy 抱他时给他装了追踪器，他觉得被背叛了。校长突然来信，说给他奖学金，请他回学校（其实是 Tanaka 安排的）。David 第一次跟队伍出任务，任务搞砸了，但大家一起逃了出来，在酒吧外庆祝。Maine 正式接纳他，同时警告他：要用这个插件，就得装更多义体。中间人 Faraday 出场，提醒他们这一行谁才有钱。 |
| 4 | Lucky You | 欢乐日常：Lucy 带 David 训练，队伍一起接各种小活，David 渐渐融进这个家。Pilar 拿到了新的金色义手。Pilar 嘲笑一个在高处撒尿的疯子，那人是赛博精神病，**一枪打死了 Pilar**。Maine 的义体手臂开始失灵。结尾 David 和 Lucy 在月亮前接吻，他答应带她去月球。 |
| 5 | All Eyez On Me | Pilar 的遗物是那双金色义手。队伍计划绑架 Tanaka，先去拉拢超梦剪辑师 Jimmy Kurosaki（David 是他的粉丝）。Jimmy 告诉 David：他的《Edgerunners》系列素材，就是那些以为自己能一直装义体的人的死亡记忆。绑架成功，Maine 的手臂又失灵了。 |
| 6 | Girl on Fire | Maine 的赛博精神病发作，打晕了 Kiwi，事后不记得。Lucy 被迫潜入 Tanaka 的脑子读数据，**发现了 Arasaka 关于 David 的档案**，但她骗 David 说什么都没找到。撤退时 Dorio 被警察打死，Maine 失控杀了 Tanaka，最后抱着 Dorio 的尸体引爆了自己。David 只带出了 Maine 的一条义体手臂。 |
| 7 | Stronger | 几个月后，David 装满义体，当上了队长，走的正是 Maine 的路。新人 Julio 第一次出任务就踩雷死了。Becca 装了和哥哥 Pilar 一样的义手。Faraday 替 Militech 给 David 派活。Lucy 讲出过去：她小时候被 Arasaka 当网络行者培养，同伴都死在了旧网里，只有她逃了出来。随后她暗中杀了一个调查 Tanaka 数据的 Arasaka 网络行者。 |
| 8 | Stay | Lucy 一直在暗中删除 David 的档案、清理追查他的人。David 和 Lucy 算月球的票钱：25 万，只是单程。David 的手开始抖，出现幻觉，战斗中僵住。Becca 偷偷喜欢他，替他保密。Lucy 求他停下，他提出分手。Faraday 和 Kiwi 设下陷阱，Lucy 被抓，要交给 Arasaka 反情报部门。 |
| 9 | Humanity | 真相揭开：Lucy 牺牲 Maine 和 Dorio、删除档案、杀人，全都是为了不让 Arasaka 把 David 抓去做实验。Kiwi 出卖了大家。所谓"Militech 的任务"其实是个圈套，为的是逼 David 穿上 Arasaka 的实验外骨骼。他穿上之后大杀四方，同时神经快速崩溃。 |
| 10 | My Moon My Man | Faraday 约 Kiwi 当面领钱，然后开枪打死了她。Arasaka 也不打算兑现对 Faraday 的承诺。David 爬上 Arasaka 大楼顶端，说"我实现了妈妈的梦想"。他救出 Lucy，Lucy 在坠落中吻醒失控的他，两人说出自己只是想保护对方。Becca 被 Adam Smasher 压死。David 托 Falco 把 Lucy 和钱带走，还让他转告"对不起，不能一起去月球了"。他笑着被 Smasher 杀死。很久之后，Lucy 独自坐观光飞船到了月球，在那里看见了当年模拟里的 David，他正兴奋地喊着太阳好热。幻影消失后，她闭上眼，张开双臂迎向太阳。她把 Gloria 的骨灰安放在纳骨堂，留言写着："你是对的，David 到了 Arasaka 大楼的顶端。" |

### 关于 Gloria 的死

wiki 的写法：创伤小组不救非客户 → 廉价医院手术 → 第二天死亡，医生说是"身体长期过劳" → 最便宜的火化，塑料骨灰盒。

"黑诊所摘器官"在 wiki 和几篇回顾文章里都没有找到。可能有两个来源：

1. 观众对那家廉价医院的怀疑。
2. 和第 2 集记混了：救护人员发现 David 没保险，就想挖他身上的插件卖掉。

不管是哪一种，**"没钱的人身体会被当成零件"这件事，原作确实明着拍了**，只是发生在 David 身上，不是 Gloria。

## 2. 它为什么打动人

### 2.1 一件东西串起所有人的死

所有的死都是被 Sandevistan 一环一环推出来的，没有一处是巧合：

1. Gloria 为了供儿子上 Arasaka 学院，偷拿 Sandevistan 去卖。
2. 她死了，插件落到 David 手里。
3. David 装上插件，Lucy 因为它找上 David。
4. Arasaka 想要 David，Lucy 为了保护他，让 Maine 和 Dorio 去死。
5. Lucy 因为保护他被抓。
6. David 为了救 Lucy 穿上外骨骼，最后死了。

**母亲的爱是起点，恋人的爱是终点，中间每一步都是"爱"在推。** 这就是双城之战那种"爱造成伤害"，原作里同样有。

### 2.2 每个人都用隐瞒来保护别人

| 谁 | 瞒了什么 | 结果 |
| --- | --- | --- |
| Gloria | 偷插件卖钱 | 死后插件落到儿子手里 |
| Lucy | 在 Tanaka 脑子里看到的东西 | Maine 和 Dorio 死了，她自己被抓 |
| David | 手在发抖 | 越陷越深 |
| Becca | David 的病情 | 没人拦住他 |
| Faraday、Kiwi | 自己的交易 | 被更高一层的人吃掉 |

悲剧不是坏人造成的，是**每个人都想独自承担、不说出来**造成的。

### 2.3 结局提前就告诉了观众

- **镜子人物**：Maine 在第 4–6 集把 David 后面要走的路完整走了一遍（装义体 → 手臂失灵 → 失控 → 死）。第 7 集 David 接替 Maine 当队长。观众知道他会走向哪里，看着他一步步过去。
- 片头最后一个镜头，就是 David 被一个巨大的身影爆头。
- Jimmy 直接说出了 David 的结局：以为自己能一直装义体的人，最后都成了他的素材。

痛苦不是来自意外，而是来自**眼看着它发生，却拦不住**。

### 2.4 愿望都实现了，但是以最糟糕的方式

- Gloria 的梦想是"儿子在 Arasaka 出人头地"。David 最后真的站上了 Arasaka 大楼的顶端，然后死在那里。
- Lucy 的梦想是去月球。她去了，一个人去的，用的是 David 用命换来的钱。

### 2.5 小物件反复出现，情感都装在里面

| 物件 | 出现的过程 |
| --- | --- |
| 洗衣机 | 第 1 集里面是泡湿的校服 → 第 2 集他回来洗母亲外套上的血 |
| 急救员外套 | 母亲的工作服 → Lucy 改成显示"Edgerunners" → David 穿着它走完全程 |
| 骨灰盒 | 一直放在家里，David 崩溃时倒在它面前 → 最后由 Lucy 安放，留下那句留言 |
| 月球 | 墙上的广告 → 被嘲笑 → 模拟 → 接吻时的背景 → 票价 25 万单程 → 最后真的去了 |
| 金色义手 | Pilar 的 → 他死后 Becca 装上一样的 |
| Maine 的手臂 | 失灵的伏笔 → David 从爆炸里只带出了这条手臂 |

### 2.6 Gloria 的死不是一场戏，是一串账单

没有坏人朝她开枪，帮派火拼只是路过。真正杀死她的是一连串"按价格处理"：

1. 创伤小组跳过非客户。
2. 只能去廉价医院。
3. 第二天死亡，死因是"过劳"。
4. 最便宜的火化，塑料骨灰盒。
5. 房租逾期，门被锁了。
6. 校长发来付款明细，还在提转学。
7. Doc 的收购价从 1 万压到 6 千。
8. 同学打电话来嘲笑。

**城市在他悲伤的每一步都伸手要钱。** 这比任何壮烈的死都更像赛博朋克。

### 2.7 中段是温暖的

第 3–5 集大部分时间是一群人一起干活、逃跑、喝酒、开玩笑。观众先爱上这个家，后面一个一个失去，才会疼。

### 2.8 反派也只是想往上爬

- Faraday 想进公司，Kiwi 想离开这座城市，Kate 和 Douglas 想升职。
- 每个人背叛别人的动机，和 Gloria 偷插件的动机是一样的：**想爬上去，想离开。**
- 他们自己也被更上一层吃掉：Kiwi 死在 Faraday 手里，Faraday 被 Arasaka 赖账，最后摔成一摊。
- 城市本身就是那个反派，每个人都只是它的一环。

## 3. 对照我们之前的草稿，缺了什么

| 原作有 | 我们的草稿 |
| --- | --- |
| 一件东西串起所有的死，每一步都是爱推动的 | 机制先行，死亡靠情节安排 |
| 每个人用隐瞒保护别人 | 角色之间没有秘密 |
| 镜子人物提前演完结局 | 没有镜子人物，或者只是口头提过 |
| 愿望以最糟糕的方式实现 | 有尝试，但比较生硬 |
| 小物件贯穿全片 | 道具只是道具 |
| 死亡是一串账单 | 死亡是一个事件 |
| 温暖的中段，一个"家" | 几乎没有日常 |
| 反派和主角动机相同 | 反派没有脸 |
