- 不要上传到 Higgsfield，不要用于成片，不要修改或去除水印。

| 前缀 | 用途 |
| --- | --- |
| `char_` | 人物：脸、眼睛、全身比例、服装画法 |
| `light_` | 光影：边缘光、环境光染色 |
| `bg_` | 背景画法 |
| `mono_` | 整屏单色画面 |
